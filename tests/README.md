# Bộ test của ことば畑 (từ bản 1.13)

Từ 1.23 **mã nguồn add-on nằm ở thư mục `kotoba_batake/`** của repo (trước đó chỉ có gói `.ankiaddon`, phải giải nén mới sửa được). Sửa ở đó, test, rồi đóng gói lại:

```bash
tests/run_all.sh                            # test offline thư mục kotoba_batake/ (đưa thư mục khác làm tham số nếu cần)
python3 tests/tools/pack.py                 # → kotoba_batake.ankiaddon ở gốc repo (tăng "mod")
python3 tests/tools/pack_test_addon.py      # (1.23) → kotoba_batake_test.ankiaddon: add-on phụ "Công cụ test", không phát hành
```
Nhớ tăng `human_version` trong `manifest.json` và ghi lịch sử phiên bản ở `PHAT_TRIEN.md` + `kotoba_batake/README.md`. `tests/tools/unpack.sh` vẫn dùng được để giải nén một gói bất kỳ (vd. gói của bản cũ để so sánh).
