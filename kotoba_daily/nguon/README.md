# nguon/ — dữ liệu trích từ giáo trình của bạn

Mỗi chương một file `nguon/<id giáo trình>/<chương>.json` (định dạng: `../vi_du/chuong_mau.json`, cách trích: `../prompts/trich_chuong.md`).

Repo công khai **không kèm** các file này (sách có bản quyền) — `.gitignore` bỏ qua mọi thứ trong thư mục này trừ file README này,
nên dữ liệu trên máy bạn không bị đẩy lên GitHub.
